Ever Programming Language

Simple, human-friendly like good old TurboC.

gen string @name def:getInput "Whats your name?"
if (@name == "Pouya")
    write ("Nice to meet you, " + @name)
end


Install it directly

curl -sL https://raw.githubusercontent.com/evrlang/ever/main/install.sh | bash

Why Ever?

Well, this language wasn't created to compete with other languages. Right now, it is in a version that isn't yet stable and contains various bugs. And I’m not going to write here that we have "X"—something that Python or C lacks.
But well, it simplifies writing code. Unlike C, it doesn't require defining a main function as the program's entry point, and it compiles to its own proprietary intermediate language.

Read Fast

Ever is easy to read and understand thanks to its simple, well-defined components. With even a little programming experience, you can easily tell what a program does just by looking at its Ever code.

Write Fast

Ever aims to keep everyday programming simple and readable. Its syntax is designed to reduce boilerplate and let developers focus on what their programs do rather than on repetitive structure.

Packages and Library in Ever

With evrpkg, you can install or publish packages—such as libraries or applications—written for Ever. It works just like npm for Node.js.

~/ever/evrpkg$ ./evrpkg install @pouya:ever-test
Download @pouya:ever-test finished.
A simple test
Install progress finished, Done.
~/ever/evrpkg$ ./evrpkg ever-test
Hello world!
~/ever/evrpkg$

You can compile it yourself from Ever Github , and use it.
