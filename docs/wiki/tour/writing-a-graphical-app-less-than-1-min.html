Creating a graphical window in less than 1 minute in Ever

written by Pouya Mohammadi

In the name of Allah, the Merciful.

In this article, I'm going to show you how to create a program with a graphical user interface in "Ever".  We'll also look at the equivalent code in other languages.

Prerequisites

At the very least, you know the difference between a graphical user interface (GUI) and a text-based interface.
If you have done some programming before, you are likely familiar with the amount of code required to implement graphical interfaces in various languages.

Midnight Commander is a console application with a text user interface.

A graphical user interface (GUI) showing various elements: radio, buttons, checkboxes, and other elements. The image shown uses the KDE desktop environment.

Well, first let me show you the program itself.

def:mainWindow ("l1" "Hello world")
def:label ("Hello :\cp" "center" "l1")
def:loopWindow "l1"

After saving this file as myguiapp.evr (the file is available in the examples section of the GitHub repository), the output of this code—when run using the latest version of the language's interpreter/compiler on Linux—will be as follows:

output of myguiapp.evr

So, this code consists of the following components:
1. The `mainwindow` function: This is a runtime function that is available with the exact same syntax on the Windows interpreter as well—though the window's appearance differs on Windows. It takes two arguments: the name of the window you wish to create and its title. Currently, this function does not support window resizing, but that is a feature slated for an upcoming release. Note that you might not be able to create multiple windows simultaneously on Windows, though this hasn't been tested.

2. The `label` function: This adds a text widget to the window you’ve created; it accepts the text content and specifies its placement.

3. The final function, `loopWindow`: This function keeps the window running in a loop until it is closed.

And that was a simple example. Let's write the equivalent of this code in C#, since I learned C# to write the interpreter on Windows:

using System;
using System.Windows.Forms;

class Program
{
    static void Main()
    {
        ApplicationConfiguration.Initialize();

        Form form = new Form();
        form.Text = "Hello world";
        form.Width = 400;
        form.Height = 200;

        Label label = new Label();
        label.Text = "Hello, World!";
        label.AutoSize = true;
        label.Left = 20;
        label.Top = 20;

        form.Controls.Add(label);

        Application.Run(form);
    }
}

* Note that in ever code, \cp is a escape sequence for ")". see escape sequence in ever .
