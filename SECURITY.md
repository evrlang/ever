# Security Policy

Note: Ever is pre-release software. Users should not assume that all security issues have been identified or resolved.

# Reporting a Vulnerability

If you discover a potential security vulnerability in Ever, please report it responsibly.

- GitHub: Open a private security advisory through the repository's Security tab, if private vulnerability reporting is enabled.
- Public issues: Do not disclose sensitive vulnerability details in public issues before the vulnerability has been investigated.

Please include the following information in your report:

- A description of the vulnerability.
- The affected version or commit.
- Steps to reproduce the issue.
- The potential security impact.

Response and Resolution

Ever is an independently developed, pre-release project. Reports will be reviewed as time permits.

If the vulnerability is confirmed, efforts will be made to investigate and address it. If a report cannot be reproduced or is determined not to be a security vulnerability, an explanation may be provided when possible.

Please allow time for investigation and remediation before publicly disclosing an unpatched vulnerability.
