
# Source Help Guide

Here is a short info about every single file in there:

1. **asmvia/qast.d**: This file is not fully finished yet.
2. **asmvia/parser.d**: Like qast, this is also not finished yet.
3. **asmvia**: A simple Assembly virtual interpreter to make ASM work on all devices with different CPUs.
4. **box_ekoheader/ast.d**: AST tree for #BOX block mode.
5. **box_ekoheader/parser.d**: Parser for #BOX block mode.
6. **box_p**: Supports box as block.
7. **csl/mempack/free.d**: Free defined here.
8. **csl/mempack/malloc.d**: Malloc defined here.
9. **csl/preprs/_sbox.d**: Supports defining box as a line.
10. **csl/preprs/define.d**: Supports defining uneditable strings or values.
11. **csl/preprs/sbox_funcprintf.d**: Functions that support box situations.
12. **clg/ultracgraphic/sgfu.d**: An unfinished graphics support library for PSL.
13. **cslm/proc.d**: ekoC (P for computer) IR Language, parser/direct executor.
14. **cslm/randomnameforvalue.d**: Creates random names for values. For example, `write("Hello")` makes "Hello" as a string in ASM and creates a random name for it, so it becomes callable.
15. **header/ast.d**: Header block AST tree.
16. **header/parser.d**: Parser for header block.
17. **pslgraekofunctions.d**: PSL Ultra-beta graphical library.
18. **pslgraekoinfssFunction.d**: Functions for use in the interpreter.
19. **app.d**: Main entry point file. It handles arguments, etc.
20. **ast.d**: Unfinished AST tree for the entire PSL.
21. **error.d**: Error printer and error functions.
22. **func.d**: Interpreter-based functions (write, return, etc.).
23. **infss.d**: Main interpreter + parser.
24. **init_prog.d**: Old argument manager.
25. **intfunc_fs.d**: Get user input function defined here.
26. **intfunc.d**: Unfinished new tokenManager.
27. **lbrk.d**: If we get any `}` in tokens.
28. **math_manager.d**: Unfinished math support functions.
29. **short.d**: Short mode manager (Golf mode).
30. **ssm.d**: Functions for exiting the app and printing a message are defined here.
31. **token_string.d**: Current tokenManager.
32. **ultracex.d**: An old error method from UltraC.
